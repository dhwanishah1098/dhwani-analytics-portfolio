# SQL Analytics Templates

**Tech:** SQL (PostgreSQL · BigQuery · Snowflake)

## What it does
A production-ready library of analytics queries covering the full
reporting stack — sales, customers, products, and finance.

## Query categories
- **Sales:** revenue MoM/YoY, pipeline conversion, target attainment, daily flash
- **Customers:** cohort retention, LTV decile ranking, churn prediction features
- **Products:** inventory health, sell-through rate, margin waterfall
- **Finance:** P&L summary, budget vs actuals, cash flow, working capital
- **Views:** customer 360, monthly KPI view, product performance summary

All queries use standard ANSI SQL with minor dialect notes for BigQuery/Snowflake.
