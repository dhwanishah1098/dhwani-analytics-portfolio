# Sales Performance Dashboard

**Tech:** Python · pandas · matplotlib · plotly · openpyxl

## What it does
End-to-end pipeline that ingests transactional data, computes KPIs
(revenue, margin, AOV, units sold), and produces interactive charts
with regional and product-level drill-down.

## Key features
- Month-over-month and year-over-year growth tracking
- Revenue forecasting using linear trend extrapolation
- Cohort retention analysis
- Automated Excel report generation with formatted KPI sheets
- ABC product classification (Pareto 70/90/100)

## Impact metrics
Designed to replace 40%+ of manual reporting effort in procurement teams.
