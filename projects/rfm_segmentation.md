# Customer Segmentation — RFM Analysis

**Tech:** Python · pandas · scikit-learn · matplotlib · seaborn

## What it does
Scores 10,000+ customer transactions using Recency, Frequency, and Monetary
metrics; classifies customers into 6 actionable segments with CLV estimation
and A/B test helper.

## Segments
| Segment | Action |
|---------|--------|
| Champions | Reward & upsell |
| Loyal Customers | Loyalty program |
| At Risk | Reactivation campaign |
| Lost | Win-back or deprioritise |

## Key features
- Configurable quantile-based scoring (3–5 bands)
- Weighted RFM score with adjustable business weights
- Customer lifetime value estimation
- Campaign ROI calculator per segment
- Geographic and channel segmentation overlays
